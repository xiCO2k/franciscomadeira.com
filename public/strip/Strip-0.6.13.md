## What's new in 0.6.13

**Secure in-app updates are now live end to end.** This small release completes the
rollout introduced in 0.6.12: Strip can fetch a signed, notarized update from its public
feed while the source repository and GitHub release remain private. Audio behavior and
controls are unchanged from 0.6.12.
